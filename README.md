# @area44/website

## Getting Started

To get started, make sure you have [Node.js](https://nodejs.org) and [Vite+](https://viteplus.dev) installed on your system. Then, follow these steps:

```bash
git clone https://github.com/AREA44/area44.github.io
cd area44.github.io
vp install
vp dev
```

Now, you can open your browser and navigate to http://localhost:5173 to see the application running.
